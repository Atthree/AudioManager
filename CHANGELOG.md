# Changelog

## [0.1.0] - 2026-11-24
- Initial version: AudioManager API (Play, PlayAt, PlayAttached, PlayClip, PlayMusic with crossfade,
  StopAll, channel volumes with persistence, pause), SoundDefinition assets with variations and spam
  protection, pooled AudioSources with priority-based voice stealing, SoundHandle.
- Components: PlaySound (Start, Enable, Disable, Collision with impact volume, TriggerEnter, Manual),
  PlayMusic (on start or trigger area).
- Editor: sound inspector with preview, create sounds from selected clips, settings asset, demo scene.
- 12 synthesized sample sounds and 9 sound assets.
- 13 PlayMode tests.
